# Linux Commands

pwd - Shows the path to the atual directory

ls - Lists the content of a repository

ls -la - Lists hidden files, with details

cd pasta -- Enters in a directory

cd .. - Goes to the past before in the hierarquie

whoami - Gives you the host7

uname -a -- Gives all information realted to the operating system that is running

ls -lh -- lista files and directories in the current folder in a long format

df -h -- reports the amount of free and used disk space on a computer file system

ip addr - shows the network interfaces configured.

ip route - shows where the traffic exits from our network, the routing table, it shows the routing table

ps aux - displays a comprehensive snapshot of all currently running processes

man ... - shows the information of a command

touch file.txt -- creates an empty file. If it already exists, updates its timestamps without deleting its contents

mkdir folder -- creates a directory/folder

cat file.txt -- displays the files contents

less file.txt -- lets you scroll through the content; press q to quit

head -n 5 file.txt  -- shows the first 5 lines

tail -n 5 file.txt -- shows the last 5 lines

grep "error" file.txt -- displays lines containing error

grep -in "error" file.txt -- ignores letter case and shows matching line numbers

wc -l file.txt  Counts newline characters—normally the number of lines.

### nano Editor

- **Alt + U** — desfaz a última alteração no texto dentro do nano.
- **Alt + E** — refaz a alteração desfeita.

Estes atalhos são usados dentro do editor nano, não na linha de comandos do terminal.
