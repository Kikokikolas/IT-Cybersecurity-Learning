# Linux Commands

pwd - Shows the path to the atual directory

ls - Lists the content of a repository

ls -la - Lists hidden files, with details

cd pasta -- Enters in a directory

cd .. - Goes to the past before in the hierarquie

## Ajudas e atalhos

### Editor nano

- **Alt + U** — desfaz a última alteração no texto dentro do nano.
- **Alt + E** — refaz a alteração desfeita.

Estes atalhos são usados dentro do editor nano, não na linha de comandos do terminal.
