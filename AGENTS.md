# Repository instructions

## English corrections

Whenever the user asks for writing corrections, record any English spelling,
vocabulary, or grammar errors you correct in `Notes/English-Vocabulary-and-Grammar.md`.

- Preserve the user's exact original wording in the “Before” column.
- Put the corrected English wording in the “Correct” column.
- Add a short explanation in Portuguese and identify the source file and review date.
- Capture the original wording before editing; never invent examples attributed to the user.
- Append new examples while preserving existing entries. Avoid repeating identical
  before/correct pairs; record a different context when it teaches a new point.
- Record actual language errors, not Markdown formatting changes or optional style preferences.
- Keep the correction log updated as part of the same task as the requested corrections.
