# Lighthouse

Lighthouse is a little different from the other panels.
It is not mainly for manually inspecting something.

Instead, Lighthouse automatically runs a set of tests against the page and
produces a report.

```text
Website
   |
   v
Lighthouse
   |
   v
Automatic audits
   |
   v
Scores, problems, and recommendations
```

The main areas it currently audits include:

- Performance
- Accessibility
- Best Practices
- SEO
