# Browser Developer Tools

## Main panels

| Tool | Purpose |
|---|---|
| Elements | Inspect HTML and CSS |
| Console | Execute JavaScript and view errors |
| Sources | Inspect and debug JavaScript |
| Network | Inspect HTTP/HTTPS requests |
| Application | Inspect cookies, storage and cache |
| Performance | Analyze page performance |
| Memory | Analyze memory usage |
| Security | Inspect HTTPS/TLS information |
| Lighthouse | Audit performance, accessibility and best practices |
