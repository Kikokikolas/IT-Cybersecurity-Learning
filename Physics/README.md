## Note Structure

These notes use the following sections where relevant:

1. **Concept:** What it means and the quantities or units involved.
2. **How it works:** A step-by-step explanation.
3. **Everyday example:** A familiar illustration.
4. **Computing application:** How it relates to hardware, networks, or services.
5. **Summary:** The main points, with a table or diagram if useful.
6. **References:** Sources used to check the explanation.
