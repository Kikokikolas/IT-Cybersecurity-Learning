# 5G

5G is the fifth generation of mobile network technology. It is designed to provide faster data speeds, lower latency, better reliability, and support for a much larger number of connected devices compared to previous generations.

## 1. What is 5G?

5G enables mobile devices to connect to the network using radio signals and a core network that manages authentication, mobility, sessions, and traffic forwarding.

A simple flow looks like this:

```text
UE -> gNB -> 5G Core -> Data Network
                  |
                  +-> Internet / Services
```

Where:

- UE = User Equipment
- gNB = 5G base station / radio access node
- 5G Core = the network control and data management layer
- Data Network = Internet, enterprise network, cloud services, or internal applications

## 2. UE - User Equipment

UE is the device connected to the mobile network. It may be:

- Smartphone
- 5G modem
- IoT device
- 5G router

The UE identifies itself to the network through a subscriber identity, such as:

- SUPI = Subscription Permanent Identifier
- IMSI = International Mobile Subscriber Identity

In simple terms, the network needs to know who the device is before allowing it to connect and use services.

## 3. SIM Provisioning and Authorization

Before a device can connect to the 5G network, the SIM is already associated with a subscriber profile in the operator's database. This profile contains the subscriber identity, service permissions, and policy information.

When the UE attempts to register, the 5G core verifies the SIM identity through authentication functions such as UDM and AUSF. The core checks whether the subscriber exists, whether the SIM is valid, and whether the user is allowed to access the requested service or slice.

If the authentication succeeds and the policy allows access, the core authorizes the session and the SMF configures the data connection. If the SIM is not associated or the identity is invalid, the network rejects the access request.

In short:

- SIM is associated with the subscriber profile before access
- 5G core verifies the identity during registration
- UDM/AUSF validate the user
- PCF checks the policy and service authorization
- SMF creates the session only after approval

## 4. RAN - Radio Access Network

The RAN is the access layer that connects the UE to the mobile network.

In 5G, the radio access node is called a gNB.

```text
UE
  ↓
gNB
  ↓
5G Core
```

This is the path of a mobile device communicating with the network.

A smartphone sends radio signals to the nearest antenna or gNB, which then forwards traffic to the 5G core.

## 4. UERANSIM

UERANSIM is a tool used to simulate 5G user equipment and radio access nodes in a lab environment.

It is commonly used to test 5G core implementations without needing physical smartphones or real radio hardware.

In a lab, you may simulate:

```text
UERANSIM UE -> UERANSIM gNB -> 5G Core
```

This is useful for learning and testing network behavior, but it does not replace real radio wave transmission or physical radio equipment.

## 5. 5G Core

The 5G Core is the central part of the architecture. It handles:

- User authentication
- Connection control
- Mobility management
- Data sessions
- Resource allocation
- Policy enforcement
- Network slicing
- Traffic routing

Main functions in a 5G standalone core include:

- AMF
- SMF
- UPF
- NRF
- AUSF
- UDM
- UDR
- PCF
- NSSF

## 6. AMF - Access and Mobility Management Function

The AMF is the main control function between the UE and the 5G Core. It is responsible for:

- Registration
- Connection management
- Mobility handling
- Access control

A simplified interaction is:

```text
UE: "I want to join this network."
   ↓
gNB
   ↓
AMF: "Who are you?"
```

The AMF is the first point that decides whether the UE can access the network and how it will be managed.

## 7. SMF - Session Management Function

The SMF manages user data sessions. After the UE is authenticated and connected, it needs a session to access services such as the Internet.

```text
Registered UE
   ↓
"I want Internet access"
   ↓
SMF
   ↓
Creates and configures the session
```

The SMF decides how the data session is established and what policies apply to it.

## 8. UPF - User Plane Function

The UPF is one of the most important functions in 5G. It is responsible for forwarding user data between the radio network and external networks.

Example:

```text
UE -> gNB -> UPF -> Internet
```

When a user opens a website, the traffic travels through the radio access network and then to the UPF, which forwards packets to the external data network.

## 9. Control Plane vs User Plane

This is a central concept in 5G architecture.

### Control Plane
The control plane handles decisions and signaling. It is responsible for:

- Who is the UE?
- Can it join the network?
- Which session should be created?
- Which policy should apply?
- Where is the UE located?

Functions such as AMF and SMF belong mainly to the control plane.

### User Plane
The user plane carries the actual user traffic, such as:

- HTTP
- HTTPS
- YouTube
- Discord
- Web browsing
- Downloads

The UPF is part of the user plane.

```text
Control Plane: AMF, SMF
User Plane: UPF
```

This separation allows 5G to manage signaling and traffic independently, which improves flexibility and efficiency.

## 10. Data Network (DN)

After the UPF, traffic reaches the Data Network (DN). A DN may be:

- The Internet
- A corporate network
- A private cloud
- An internal service platform

A simplified data path is:

```text
UE -> gNB -> UPF -> DN
```

This is the standard user data flow in 5G.

## 11. Key 5G Interfaces

The main interfaces in a 5G architecture are:

### N1
UE ↔ AMF

### N2
gNB ↔ AMF

### N3
gNB ↔ UPF

### N4
SMF ↔ UPF

These interfaces enable the exchange of signaling and user data between the radio access network and the core network.

## 12. Why 5G Matters

5G is important because it supports modern digital services such as:

- Smart cities
- Autonomous vehicles
- Industrial automation
- Remote surgeries
- IoT deployments
- High-quality mobile streaming
- Low-latency enterprise applications

## 13. 5G Advantages

- Higher throughput
- Lower latency
- More capacity for connected devices
- Better support for real-time applications
- More efficient traffic management
- Network slicing for different service requirements

## 14. 5G Security

5G improves security compared to earlier generations, but it also increases the attack surface because it connects more devices, services, and virtualized functions.

Important security concerns include:

- Compromised IoT devices
- Misconfigured network slices
- Weak API security
- Virtualized network attacks
- Privacy issues related to location and user data
- Supply-chain vulnerabilities

Security controls include:

- Strong authentication
- Encryption of traffic
- Network segmentation
- Secure API management
- Monitoring and logging
- Patch management
- Least-privilege access

## 15. Summary

5G is a mobile network designed for speed, scale, and flexibility. Its architecture is based on a radio access network, a core network, and a user-plane forwarding function that carries actual traffic. The main concepts to understand are:

- UE: the connected device
- gNB: the radio access station
- AMF: access and mobility management
- SMF: session management
- UPF: user data forwarding
- DN: the external data network

Understanding these components is essential for learning how 5G networks operate and how they differ from 4G and earlier mobile systems.
